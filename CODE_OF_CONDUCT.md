# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, in full.

In short: participants are expected to behave respectfully, and harassment of
any kind is not tolerated — in issues, pull requests, discussions, or anywhere
else the project's community gathers.

## Reporting

don't align with this Code of Conduct, and may temporarily or permanently ban
